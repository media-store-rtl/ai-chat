# AI Chat — ai.mymedimo.ir

رابط گفت‌وگوی شخصی فارسی با Ollama روی همان سرور cPanel.

## معماری
- رابط کاربری ایستا با HTML/CSS/JavaScript در `public/`
- بک‌اند PHP در مسیر `api/` برای ارتباط با Ollama روی `127.0.0.1:11434`
- سرویس Ollama فقط روی localhost در دسترس می‌ماند و نباید مستقیماً به اینترنت منتشر شود.
- قبل از استفاده عمومی، احراز هویت اجباری و محدودسازی درخواست‌ها باید پیاده‌سازی شود.

## وضعیت
این commit فقط اسکلت رابط کاربری را اضافه می‌کند. API و ورود امن در مرحله بعد تکمیل می‌شوند.

## استقرار cPanel
Document Root دامنه `ai.mymedimo.ir` باید روی `/home/mediast1/ai-chat/public` باشد. فایل‌های محرمانه مانند تنظیمات و هش رمز عبور نباید داخل مخزن عمومی یا پوشه `public` قرار بگیرند.
